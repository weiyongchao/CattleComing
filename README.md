# 量价罗盘：A 股实时评测

一个零第三方依赖的本地 Web 项目。输入 6 位 A 股代码，读取实时成交价、涨跌幅、成交量及近 30 个交易日行情，以五日均线和五日均量生成可解释的 0–100 分规则评测。

## 启动

要求 Python 3.10 或更高版本：

```powershell
python run.py
```

浏览器打开 <http://127.0.0.1:8000>。也可以指定端口：

```powershell
python run.py --port 8080
```

运行测试：

```powershell
python -m unittest discover -s tests -v
```

## 评分模型

基础分为 50 分，六项信号叠加后限制在 0–100：

- MA5 趋势（±20）：现价相对五日均线的位置。
- 今日动量（±15）：实时涨跌幅。
- 昨日动量（±10）：最近完整交易日的涨跌幅。
- 量比（±10）：当前成交量相对近五日平均成交量；上涨放量加分，下跌放量减分。
- 换手率（±5）：交投活跃度对评分的有限修正。
- 日内位置（±10）：现价处于今日最低价至最高价区间的位置。

评分是透明的启发式规则，不是机器学习预测，也不构成投资建议。盘中累计成交量直接与完整交易日均量比较，早盘量比通常偏低，这是模型边界之一。

页面还会根据评分、MA5、量比、换手率和日内位置，分别生成未持仓建仓参考、已有仓位加仓/持有参考、确认条件、失效条件及动态风险点。操作提示不包含个人风险承受能力、投资期限和整体资产配置，不能替代个人投资决策。

## 打板精选与条件预警（2026-08-31）

- 09:25只建立观察池，前台优选观察最多5只，其余折叠；竞价不直接产生执行仓位。
- 09:30–11:30、13:00–14:57动态复核；09:35后继续扫描昨日首板/连板股，但只补入涨幅至少9%的近封板观察标的，发现时间独立记录，不倒写竞价结果。
- 正式提示默认只有**一只首选**，全天累计最多**5个不同代码**，不是每轮5只；观察池不占名额，不主动弹窗。符合用户“只想买一只、少而精”的偏好，不达标可以一只不选。主板、非ST/退市、上市至少60个交易日、流通市值小于200亿元，并购重组及高异动风险硬剔除。公告未核验、当日资金或五档数据缺失不升级。
- 封板优先：涨停价实际成交、五档无卖盘且有买盘，盘中评分≥80、延续评分≥60、成交额≥5000万元、盘口失衡≥15%、当日主力占比≥-1%。至少两次间隔20秒的有效采样，间断超过90秒、数据缺失或炸板重置。
- 极强开盘例外仅09:30–09:35：已满足原有高换手强竞价连板通道（真实09:25换手>1.2%、高开≥5%、竞价额>5000万元），另需竞价及当前涨幅均在[5%,8.5%)、较开盘≥0.5%、不弱于竞价、盘中评分≥90、延续评分≥75、盘口失衡≥35%、当日主力占比≥3%，且非回踩/晚封/异动观察股；同样需两次采样并成为唯一首选。
- 首选额外门槛：历史延续≥75，潜力评分≥80。公式为历史延续×45% + 盘中确认×30% + 主力占比（限制在0–10）×1.5 + 盘口失衡（限制在0–1）×10；异动观察扣10分、开盘回踩和晚封各扣5分。先封板优先，再按潜力评分择优，页面展示评分依据。该分数不是收益概率或预测盈利。
- 首选仍合格就保持，不随每轮排名波动换票；数据缺失先暂停买点，不立即用备选替换。确认失效后才考虑新首选，失效代码当日不自动回榜。每日名额及首选保存在 `data/board_daily_focus.json`，刷新和重启不重置；记录损坏或写入失败则停止新增提示。当前单进程服务内的并发请求共享锁和记录，不支持多个服务进程共写同一账本。
- 点击“今日只关注这只”后，不再提示其他买点；保留已提示股票的风险监控。锁定不等于已成交、不下单、不加仓；取消锁定也不返还当日名额，下一交易日重新计数。只关注一只不代表满仓。
- 浮窗只提示唯一首选及已提示股票的风险；竞价/普通新增观察固定静默。每个代码每日只发一次正向提示，切换确认类型不重发；风险按代码+条件去重。沿用浏览器旧记录，清空展示记录不清空当日名额。历史/过期数据不触发；移出首选、锁定或60秒没有新扫描后标记为历史记录。风险记录可使总条数超过5，但新股票提示最多5只。
- 预警范围固定为**北京时间今天的正式打板名单**：实时快照日期和服务端首次提示日期均必须是今天。买点、风险、浮窗记录、未读数和打开股票入口共用同一名单；普通观察票、历史票及旧本地缓存股票不能自行加入。竞价快照一律不触发预警；今日名单未确认时先不展示旧缓存。旧记录仅被隐藏，不因升级删除，已使用的当日名额仍保留。
- 策略页或打板页交易时段每20秒尝试刷新，页面关闭后停止；支持暂停、隐藏、最小化、拖动、选股打开、声音及需授权的桌面通知。不自动下单、不自动撤单。
- 股票详情默认收起：竞价候选、盘中首选、盘前预选、次日预案及策略执行详情均支持单只独立展开/收起。点击股票标题栏操作，收起时保留名称、代码、价格/涨幅、核心结论与高风险标记；展开后查看原有完整数据。浏览器按日期、区域和股票代码记住状态，20秒自动刷新、重排及页面刷新不强制展开，也不影响其他股票。仅保存显示偏好，不改变选股与预警规则。
- 新版接口将当日旧快照转成只读观察视图，原始历史文件不清除、不覆盖。服务重启会清空内存采样计数，需要重新确认。

这些是保守的可解释筛选阈值，尚未证明能提高收益或降低炸板率。两次离散采样不等于期间持续封板，公开行情也可能延迟，成交额/主力分类并非交易所逐笔买卖意图。封单可撤、排队不保证成交，不能回填“开盘买入”的收益。[上交所关于封涨停申报风险的说明](https://www.sse.com.cn/aboutus/mediacenter/conference/c/c_20160722_4146612.shtml)

离线验证：`python -m unittest discover -s tests`、`node tests/test_board_alerts.js`、`node tests/test_board_alert_today.js`、`node tests/test_stock_card_details.js`。浏览器回归可运行 `python tests/board_alert_fixture_server.py`，只在 `127.0.0.1:8001` 提供标注“测试股票”的假数据，不请求行情也不写业务数据；折叠交互回归脚本为 `tests/stock_card_browser_checks.js`。

## 数据与参考项目

- 行情数据：东方财富公开行情页面的实时行情接口；连接失败时自动降级到腾讯实时行情。历史数据使用腾讯证券公开页面的前复权日线接口。接口可能调整，仅限学习研究。
- [AKShare](https://github.com/akfamily/akshare)：A 股实时/历史数据接口设计参考。
- [yfinance](https://github.com/ranaroussi/yfinance)：全球证券行情数据封装参考。
- [ai-stock-dashboard](https://github.com/ErikThiart/ai-stock-dashboard)：技术指标仪表盘与评分展示参考。
